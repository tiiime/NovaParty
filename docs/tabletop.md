# 象棋与 9 路围棋

两个游戏都是 SDK 1 的独立双人 Mod：房主校验落子并发布快照，没有单机 AI、在线匹配或观战。基础客户端仍只内置五子棋。游戏规则不直接调用 Wi‑Fi、蓝牙、时钟或宿主场景。

```bash
python3 tools/build/pack_mod.py mods/xiangqi build/xiangqi.zip
python3 tools/build/pack_mod.py mods/go build/go.zip
```

在「选择游戏 → 添加游戏」导入 ZIP，选择游戏并启动。另一台设备可扫码、搜索附近游戏或手动输入局域网地址；未安装兼容包时可确认从房主下载。设置、邀请、离开和重连由平台处理。开始对局后断线时暂停操作，同一会话恢复原座位和棋盘。

| 游戏 | 本版规则 |
| --- | --- |
| 象棋 | 标准 9×10 开局、红先。自由走棋：轮流移动己方棋子到任意空交点或吃掉对方棋子；不检查棋子的走法、阻挡、九宫、将军或重复局面。吃掉将帅或认输结束本局。 |
| 围棋 | 9×9、黑先、白贴 7.5 点，禁止自杀以及重复任何先前的棋盘局面（位置超级劫）。连续两次停一手进入面积计分（存活棋子 + 单方围住的空点）；点击棋块可一起标记或恢复，修改会取消双方确认。双方确认才结算，也可恢复原棋盘继续下。极端情况下第 512 手落子后进入计分，不再续弈；仍可修改死子、确认或认输。暂无 13/19 路、让子、用时或自动死活判断。 |

象棋点击己方棋子选中，再点目标，不限定走法；黑方视角将棋盘旋转至己方在下。最后走棋的一方可申请撤回一步，对方收到「同意撤回 / 拒绝撤回」，等待期间暂停走棋，发起方也可取消。只有同意才恢复移动和被吃的棋子、上一步标记及轮次；连撤需逐步取得同意。吃掉将帅的一步也可撤回（发起复赛之前），认输不撤回。围棋计分时，被标记棋块用淡化与叉号一起表示，不只靠颜色。电视/键盘用方向键移动、确定键操作，棋盘右或下边缘可转到操作区，也可用 Tab。认输需要二次确认，默认焦点在「继续对弈」；双方同意才开始下一局。中文、英文和未支持语言回退包含在各自的 Mod 包内。棋盘与棋子在 Godot 绘制，未复用参考应用资产。

## 验证

- `tests/unit/tabletop.gd`：自由走棋、轮次与己方棋子校验、双方撤回与恢复吃子，围棋提子、自杀与劫、数子、更改与重新确认。
- `tests/unit/tabletop_ui.gd`：鼠标模拟触点、方向键、焦点边界、短屏设置、UNO 拓宽、计分与本地化。桌面渲染时加 `-- --captures=/absolute/path` 可保存 PNG；`--headless` 不渲染图片。
- `python3 tests/integration/tabletop_network.py`：两个独立客户端过真实 TCP 安装、联机、拒绝非法操作、切断并恢复同一座位（保留象棋撤回申请）、结算、复赛。象棋 0.2.0 变更了规则，两端需要兼容包，旧对局不能途中切换。
- `python3 tests/integration/bundled_mods.py`：检查导出仍只内置五子棋；隔离的导出包能用「添加游戏」安装外部游戏。

手机尺寸和电视宽屏布局在 macOS 上渲染验证；这两个游戏尚未在实体手机/电视上跑完对局，未进行新的实机 BLE 验证。
