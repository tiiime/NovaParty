# 星星大作战 UI 设计规范 v0.5

本目录是平台 UI 的设计依据，面向后续开发者与 AI。参数以 [`tokens.json`](tokens.json) 为唯一来源；SVG 是由参数生成的说明图，不是运行时界面资源。

## 设计方向

方向为 **「派对街机 / Party Arcade」**：暖白底、纯蓝主展台、星黄主操作。组件使用纯色块、2 单位描边、4 单位厚底边（lip），按下时 lip 消失且面下沉，布局不跳动。字体使用 Noto Sans SC，标题 800、标签 700、正文 500。

参考本地 `Duo.latest.apk`（Duolingo Android 6.96.2-china）启动与欢迎页：上部以品牌和插图区建立场景，页底主次操作分明，留出大量呼吸空间。只借用结构、按钮反馈和交互节奏，未导入 APK 图形、字体或动画。使用 UI/UX Pro Max 的 `--design-system` 及触感、焦点和错误恢复查询；采用单主操作、清晰反馈与可见焦点，不采用不适合 TV/低端手机的重 3D 推荐。

## 参数与生成

[`tokens.json`](tokens.json) 是颜色、尺寸、字重、动效和触感参数的唯一来源。不要在业务 UI 中复制 token 色值。

```sh
# 生成运行时常量 app/ui/theme/tokens.gd
python3 tools/design/build_design_tokens.py

# 检查运行时常量是否过期
python3 tools/design/build_design_tokens.py --check

# 生成 docs/design/*.svg
python3 tools/design/build_design_sheet.py

# 渲染预览到 build/design/*.png
swift tools/design/render_design_sheet.swift docs/design/0*.svg
```

## 大厅与导航

| 入口 | 流程 | 始终明确的信息 |
| --- | --- | --- |
| 选择游戏 | 选封面 → 启动 → 在游戏等待区邀请朋友 | 固定栏显示所选游戏；人数来自清单；二维码可重新打开 |
| 加入游戏 | 附近 / 蓝牙 / 扫码 / 地址 → 检查兼容性 → 必要时确认下载 → 等待握手 | 不要求先猜选游戏；显示下载进度、可取消；失败返回原入口并保留输入 |
| 进入对局 | 收到第一份过滤快照 → 进入 Mod → 按玩法等待或行动 | 自己的身份、当前回合、提交状态、连接恢复和离开后果 |

返回键先关闭当前弹层，再退回上一级。离开进行中的对局必须确认；确认对话框默认聚焦取消等安全选项。错误恢复不得清空用户配置或有效输入。

## 电视焦点

电视或键盘焦点使用橙色 6 单位外环、深色细轮廓与奶白内边。聚焦按钮放大 `1.045`，卡片放大 `1.035`；减少动态效果时保留静态边界，但取消缩放过渡和呼吸。

**焦点不等于选中**：焦点表示确认键将操作谁，选中表示当前值。卡片即使已经选中，也必须能独立显示焦点。焦点环要预留空间，不能被滚动容器或父节点裁切。

## 反馈与状态

| 状态 | 展示 | 行为 |
| --- | --- | --- |
| 按下 | 面下沉 4，厚底边消失 | 立即响应，不等待网络结果 |
| 创建 / 加入中 | 正在创建… / 正在加入… | 防重复提交，保留取消或离开方式 |
| 搜索中 | 正在搜索附近游戏… | 可取消，不显示假进度 |
| 无结果 | 未找到游戏及下一步建议 | 提供重新搜索或手动输入 |
| 等待朋友 | 人数、游戏与连接状态 | 保留明确离开入口 |
| 提交中 | 正在落子… / 正在提交… | `queued` 不等于最终成功 |
| 断线 | 自动恢复时显示正在重连；超时后说明恢复条件 | 保留对局与原座位；仅可手动重试时显示重连 |
| 失败 | 原因与重试入口 | 状态持续可见，保留输入 |
| 胜负 | 结果文字与一次短庆祝 | 不遮挡最终棋盘或牌面 |

声音与触感仅作辅助；关闭后仍必须能从文字、状态和图形理解结果。

## 触感反馈

| 类型 | 时长 | amplitude | 用途 |
| --- | ---: | ---: | --- |
| `tap` | 12 ms | 0.35 | 任何按钮按下、开关切换 |
| `select` | 18 ms | 0.5 | 选中游戏、角色、配色 |
| `confirm` | 28 ms | 0.8 | 启动游戏、保存、加入成功 |
| `warn` | 40 ms | 1.0 | 失败、被拒绝的操作 |

触感只在 Android / iOS 触屏设备生效，电视与桌面忽略。设置中的「触感反馈」可关闭，并与音效开关相互独立；方向键移动焦点不震动。Mod 可通过：

```gdscript
platform_action.emit("haptic:select")
```

请求触感。旧版宿主会忽略未知动作，因此 Mod 不得依赖震动完成必要交互。

## 无障碍与动效

- 正文对比度不低于 `4.5:1`；状态不能只用颜色表达。
- 音效与触感均可关闭。
- 减少动态效果时取消弹层上滑与缩放过渡，并停止循环动画和庆祝运动；保留静态焦点、文字与图标。
- 最小触控区域、页面边距、电视安全区及字体均从 token 读取。

## 平台与 Mod 分工

平台负责品牌、首页、选择/加入流程、设置、连接反馈、返回行为、焦点语义及无障碍基线。Mod 可以拥有自己的棋盘、牌面和完整美术，例如 UNO，不强制使用蓝天背景。

Mod 不得 import `app/` 代码；它必须能在兼容旧宿主中独立加载。`mods/gomoku/ui.gd` 是 Mod 内自带的同风格副本，而不是对平台主题的代码依赖。平台与 Mod 通过 SDK 信号、快照和 `platform_action` 协作。
