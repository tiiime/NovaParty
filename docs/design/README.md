v0.3，2026-11-01。**星际派对：饱和蓝天空、亮黄星星、蓝白玩具质感；信息精简，开局更有庆祝感。**

这是后续客户端与 Mod UI 的设计依据，与实际实现范围一起阅读。用户确认的方向及“不够喜庆”的反馈见 [需求记录](brief.md)；本版加入立体星星、舞台、厚胶囊与周边彩带供审阅，具体数值、表情和文案可继续调整。当前项目开发代号仍为 NovaParty，0.1.6 已落地此方向的首页与 i18n，实际范围见 [UI 实现说明](../ui.md)；图标及全部后续页面并未同时重做。

## 大厅与导航

首页仅放两个主要入口：**开始游戏、加入游戏**；设置稳定放在底部，移除昵称入口。星星伙伴负责欢迎、等待与短暂庆祝，不承担唯一的状态解释。

| 入口 | 流程 | 需要始终明确的信息 |
| --- | --- | --- |
| 开始游戏 | 封面网格选择游戏 → 启动游戏 → 等待朋友 | 所选游戏、启动结果、连接状态、离开入口 |
| 加入游戏 | 搜索房间 → 选择当前可加入的房间 → 加入 → 等待确认 | 搜索状态、可加入房间、加入进度、失败后的下一步 |
| 进入对局 | 双方准备好后进入游戏 | 自己的身份、当前轮次或待响应动作、连接状态 |

游戏选择采用响应式封面网格，缺少封面时使用默认星星封面；末位为加号“添加游戏”。返回与设置固定底部，主操作为“启动游戏”，不向用户引入房间概念。此前 SVG 中的昵称与房间流程只作旧版风格参考，以本段和 [实际 UI 说明](../ui.md) 为准。当前代码还没有自动发现房间；现有手动地址加入方式暂时仍需保留，不能用静态房间卡片冒充发现结果。

返回键遵循：先关闭当前弹层，再退回上一级。进行中对局的离开应明确提醒会断开当前房间；不要让遥控器一次误按就结束对局。昵称不再作为可设置字段；错误恢复不清空用户配置。

## 颜色与时间

用语义 token 引用颜色，不在每个控件里散落色值。星光黄用于主要动作；青色与深蓝组合用于焦点，蓝色用于工作提示；绿、红用于带文字的成功/失败状态。主按钮为深蓝文字配黄底，不用白字配黄底。普通正文对比目标为 4.5:1；图标、焦点和状态需要单独验证。禁用状态还必须真的不可操作。

天空按设备**当地时间**在晨、日、暮、夜四个蓝色锚点之间循环插值。一天内只轻微改变背景和装饰色，内容面板保持明亮，正文、按钮、焦点和状态语义不随时间跳变。暂不加入定位、天气请求或服务端时间依赖。跨午夜连续插值，不在整点突然切一套皮肤。减少动态效果时保留时间对应的静态天空，停止装饰运动和过渡动画。

星星伙伴采用亮黄五角轮廓、暖色下沿、浅色高光、小眼睛和简单嘴形，呈现充气玩具般的体积。默认表情亲切，等待表情保持清醒。庆祝短暂出现并结束；错误状态使用平静表情，不能嘲笑或责备玩家。星星、云朵不穿过按钮、棋盘或手牌，不做持续吸引注意力的弹跳。

## 字体、尺寸与焦点

沿用仓库已有 Noto Sans SC。正文正常字重 400，标签与分组 500–600，标题 600–700。避免过细字体；字号不够时换行或调整布局，不自动缩到难以阅读。所有数值是逻辑单位，手机参考画布 390 × 844，电视 1280 × 720。

| 项目 | 手机 | 电视 |
| --- | --- | --- |
| 正文 / 行高 | 17 / 26 | 24 / 34 |
| 页面标题 / 行高 | 28 / 36 | 40 / 52 |
| 基础按钮高度 | 52 | 64 |
| 最小命中区域 | 48 × 48 | 64 × 64 |
| 页面边距 | 16–24，加系统安全区域 | 外围建议 48，真机校准 |

首页主按钮可以比基础按钮更大。间距使用 4、8、12、16、24、32、48；输入框 R12、卡片 R28、面板 R32；按钮为胶囊，实际圆角取高度的一半（token 999 表示尽量圆）。白色外壳配冷蓝下沿，黄色主按钮配金色下沿；下沿厚 8，按下时主体下沉 4，预留空间以免布局跳动。高光采用简短亮边，不堆叠反光纹理。

电视焦点使用 5 单位青色外环，中间保留 6 单位稳定蓝色间隙；白底和黄底也必须保留深蓝边界以保证辨识。给外环留空间，避免被父容器裁切。焦点表示“确认键将操作谁”，选中表示“当前值是什么”，两者必须区分。禁用项跳过导航；首次进入页面给出合理默认焦点；异步列表刷新按稳定 ID 保留焦点，目标消失后转到最近可用项。房间卡片整体作为一个焦点，加入标签不额外生成重复焦点。关闭弹窗恢复原焦点。

不把任何必要操作藏在悬停、右键或仅触屏手势中。手机触摸与模拟鼠标事件只能触发一次操作。刘海和底部手势条按系统实际安全区域处理。

## 反馈与状态

| 状态 | 建议文案 / 展示 | 行为 |
| --- | --- | --- |
| 按下 | 立即变色或轻微下沉 | 建议 100–140ms；不等待网络才响应 |
| 创建 / 加入中 | 正在创建房间… / 正在加入房间… | 同一请求期间防重复提交，保留说明和退出方式 |
| 搜索中 | 正在搜索附近房间… | 与列表区的空白占位配合；可取消，禁止假进度 |
| 无结果 | 还没找到房间 / 确认设备在同一局域网 | 提供重新搜索；不展示虚构房间或永久转圈 |
| 找到房间 | 找到 N 个可加入房间 | 列表显示游戏、房间名、人数；若继续后台搜索需另说明 |
| 等待朋友 | 等待朋友加入 · 1 / 2 | 保留房间与游戏信息，离开入口明确 |
| 可行动 | 你的回合 / 请选择一张牌 | 行动区域清楚可用，等待方有明确等待说明 |
| 提交中 | 正在落子… / 正在提交… | 可用临时选中提示；不把 queued 当作最终成功 |
| 已确认 | 落子结果、已选择、回合更新 | 以权威回执和最新快照为准 |
| 断线 | 连接已断开 | 正在自动恢复才显示“正在重连…”，否则提供重连按钮 |
| 失败 | 没连上房间 + 原因 + 再试一次 | 保留输入；失败状态持续可见，不靠一闪而过的提示 |
| 胜负 | 结果文字 + 一次短庆祝 | 不遮挡最终棋盘或牌面，明确下一步 |

焦点与面板过渡建议 180–240ms，庆祝 450–650ms 后停止；大厅可静态摆放最多 12 片周边彩带；开房成功、朋友到齐和胜利可以触发一次短粒子庆祝，结束后清除。进入对局后收起大厅装饰。持续工作状态允许小型进度指示，不让整个星星角色循环跳动。动画中也可执行操作，不能用动画时长阻塞网络结果。减少动态效果时移除位移、缩放、循环与庆祝动画，用静态表情、文字和图标提供等价反馈。

设置提供“音效”和“减少动态效果”，立即生效并保存。音效仅为辅助，关闭后保留所有视觉反馈。默认音量和开关在设备联调时再定；不默认引入背景音乐。

## 平台与 Mod

平台统一品牌、首页、创建/加入流程、房间信息、设置、连接提示、返回行为和焦点语义。游戏可以自行设计棋盘、棋子、牌面、背景和游戏内美术，不强制套蓝天或黄色按钮。

所有游戏共同遵守：玩家可见信息过滤、输入只提交一次、当前任务/回合明确、异步操作有反馈、手机可触摸、电视可方向导航、可读文字，以及提示不遮挡关键操作区域。平台提示和 Mod 应约定可用空间，不把连接横幅直接盖在棋盘上。去重、权威回执和重连由 SDK 负责，UI 只呈现真实状态。

## 维护与交付检查

先修改 `tokens.json`；生成器读取核心语义色，材质渐变、组件排版和示例说明在生成器中维护。参数改变后核对渐变、色值、焦点与尺寸是否一致，再重新生成并渲染检查。此版尚未自动导入 Godot Theme。

```sh
python3 tools/build_design_sheet.py
# macOS：使用系统 AppKit 和仓库字体生成预览到 build/design/
swift tools/render_design_sheet.swift docs/design/01-foundations.svg docs/design/02-components.svg docs/design/03-layouts.svg docs/design/04-party-lobby.svg docs/design/cheat-sheet.svg
```

交付前检查页面只有明确主任务，布局不被安全区域遮挡，电视焦点完整可见；验证加载、无结果、失败、断线、终局等状态；在减少动态效果与关闭音效下仍可理解并完成流程。SVG 渲染检查不替代手机和电视上的实际测试。

## 本版参考与变化

参考 [Astro Bot 官方页面](https://www.playstation.com/en-us/games/astro-bot/) 的主视觉与预告画面（查看日期 2026-11-01），提取饱和蓝空间、蓝白圆润材质、青色亮边和角色姿态。这是对官方视觉的设计解读，未将网页商店控件当作游戏 UI 规范。

v0.3 的角色与图形用 SVG 重新绘制：星星仍是黄星星，不使用 Astro Bot 的机器人形象、品牌标志或游戏素材。首页的两大入口、房间流程和游戏内部美术自由沿用既有需求。用户已确认此版视觉方向，并要求实际启动界面加入公转、缩放等轻量动效；0.1.6 已开始应用，页面示意中尚未实现的搜索能力仍保持明确标注。

## 实际组件

首页实现见 `app/ui/party_home.gd`，平台材质见 `app/ui/party_theme.gd`，设置面板见 `app/ui/settings_panel.gd`。新增平台文案与游戏 Mod 文案时遵循 [i18n 开发规则](../ui.md)。设计参数目前由代码实现对应主题，并非运行时直接加载此目录 JSON。


电视焦点实机修订：浅青色亮边在电视上辨识度不足，运行时改用橙金 #FF8A1C + 深色 #263461 外轮廓 + 奶白内边。聚焦按钮放大至 1.045，卡片 1.035；150 ms 过渡、0.65 Hz 柔和光晕；减少动态效果保留静态焦点。对应 tokens 已更新，旧版 SVG 中青色亮边示意保留为历史提案。
