# 星星大作战 · UI 设计需求

状态：基础需求已确认；用户已接受 v0.3 星际派对方向，0.1.6 开始落地真实首页。组件数值和示例文案为设计建议，尚待实现验证。

## 已确认

- 名称：星星大作战。
- 气质：轻松可爱、圆润软萌、配色轻快，像朋友聚在一起玩。
- 使用场景：朋友聚会，手机与电视混合使用。
- 品牌意象：黄色星星、蓝色天空；可以包含日夜主题变化。
- 星星伙伴：一个简单的星星角色，负责欢迎、等待和庆祝。
- 信息与反馈：信息精简、当前任务明确；操作及时有反馈，清楚展示正在做什么，减少干扰。
- 大厅主入口：开始游戏、加入游戏。
- 开始游戏：封面网格选择游戏 → 启动游戏，不向用户展示房间概念。
- 网格末位为加号“添加游戏”，支持默认封面；返回和设置固定在底部。昵称不提供设置。
- 加入游戏：搜索并展示可加入的房间。
- 美术边界：大厅保持统一；各游戏内部可以有自己的美术风格。

## 后续确认

- 天空跟随设备当地时间缓慢改变色调，变化轻微，保持接近的亮度与稳定的界面结构。
- 采用短动画反馈；音效可关闭；提供减少动态效果选项。
- 面板与按钮采用软糖质感：大圆角、柔和色块、轻微阴影。
- 用户提供蓝天与黄色星星参考图：借鉴亮黄星形、简洁表情、细描边与清爽天空。

## 待细化

- 星星伙伴最终造型、名字、具体表情与动画曲线。
- 各具体游戏页面；平台游戏选择已采用封面网格。
- 音效默认开关与音量，时间段色值过渡的最终微调。

## 初稿范围

SVG design cheat sheet 将包括品牌与角色、语义颜色、字体层级、间距与形状、按钮状态、电视焦点、连接与等待反馈、手机／电视大厅示意、房间流程，以及平台与 Mod 的视觉边界。

规范中应区分：用户已确认的需求、设计建议和当前代码的实现状态。搜索房间属于目标交互，当前客户端仍需手动输入地址；视觉稿不能视为自动发现功能已经完成。首页与封面网格已实现；应用图标仍待设计。

## v0.3 迭代依据

用户反馈 v0.2 “有点单调，不够喜庆”，指定参考 Astro Bot 的 UI 风格。新提案加强饱和蓝背景、充气星星、白色玩具外壳、厚胶囊按钮、青色焦点亮边和周边彩带。保留信息精简、真实反馈、轻量动画与减少动态效果选项。用户随后接受此方向，并要求实际启动界面加入公转、星星大小变化等轻量动效，同时记得游戏 i18n。
