# 用户角色 UI cheat sheet

[SVG 规范与角色色板](cheat-sheet.svg)。首页在「选择游戏」「加入游戏」下方增加「用户信息」，原设置入口保留。

界面顺序为预览、名字、角色、角色配色、个人主题色。手机采用三列动物卡片、可滚动内容及固定保存/取消；宽屏电视采用六列角色、四列配色、六列主题色，保留相同信息顺序，支持方向键和确认。选中状态用勾选与描边，焦点用橙色光圈，两者分开。昵称最长 32 个字符，留空使用系统设备名；系统名称不可读取时回退设备型号，再回退系统名称。

六个角色：`bear` 小熊、`fox` 狐狸、`bunny` 兔子、`cat` 小猫、`dog` 小狗、`panda` 熊猫。小猫增加胡须与额纹，狐狸使用尖耳与 V 形白脸，熊猫保留眼圈。

个人主题色提供天空、紫罗兰、玫瑰、薄荷、橘子、蜂蜜，用于首页个人入口、用户预览以及 Mod 中的身份强调色。大厅天空仍按时间变化，各游戏自行决定如何使用主题色，不强制改动棋盘或牌面规则颜色。

24 种角色外观独立于主题色。初始组合由本地随机身份 ID 的稳定散列分散分配，用户可自行更换；这是减少撞角色，不保证全局唯一，也不会擅自改动其他人的选择。必要时以平台公开代号区分同名或同头像用户。

保存后原子替换本地配置并刷新首页。取消/返回丢弃草稿；保存失败留在编辑页并提示。默认名称以空昵称保存，避免把当前设备名永久写成自定义名字。已有自定义名字、语言、声音、减少动态效果及本地身份 ID 均保留。当前编辑仅通过首页进入。

矢量源由 `tools/build_profile_design.py` 生成，公共资源位于 `assets/ui/characters.json`，共 24 个独立 SVG。SDK 在本地解码并缓存头像纹理，不通过网络传图片。协议见 [用户配置 SDK](../../user-profile.md)。
