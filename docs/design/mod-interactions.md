# Mod 交互走查

参考 UI/UX Pro Max 的可见焦点、触控安全区、阻断型弹层和错误恢复规则，以及 Duolingo 的单一主任务、明确动作分组与按压反馈。保留每个游戏的视觉风格，不把同一套视觉模板套到桌面、手牌和体感模式上。

| Mod | 入场 / 对局 / 恢复检查 | 界面调整 |
| --- | --- | --- |
| 五子棋 | 发起等待 → 棋盘落子 → 累计用时 → 结算、复赛；网络中断时停表 | 邀请在设置正下方，两个按钮同列；关闭设置恢复焦点。 |
| UNO | 等待、扫码、公共屏与手机手牌 → 出牌/摸牌 → 结算；保留连接与手牌 | 全视口背景，前景避开安全区；菜单与手牌可用宽度随屏幕扩展。菜单内提供邀请与重连、方向键循环；离开弹层回到菜单按钮。 |
| 斗地主 | 等待 → 叫分 → 选牌/提示/过牌 → 结算；保留桌面和私有手牌 | 大厅菜单提供平台邀请；方向键循环只访问可见动作，关闭设置和邀请后回到菜单按钮。 |
| 暗牌 | 等待 → 选牌 → 已提交且内容不泄露 → 同时亮牌；网络丢失后恢复 | 固定手牌不因状态或语言刷新被重建；选中与提交继续使用原视图反馈；邀请/退出在平台操作栏。 |
| 跳绳 | 选大屏/体感角色 → 等待/校准 → 计数；无传感器或暂停时不可误操作 | 除大屏 QR 外，平台邀请可直接访问；设置/邀请关闭后恢复原动作焦点。不修改计数或角色规则。 |
| 象棋 | 等待 → 自由走棋 → 吃将/结算 → 双方复赛 | 区分选中棋子、最后一步和方向焦点；撤回暂停走棋，对方明确同意才生效。 |
| 围棋（9 路） | 等待 → 交替落子/停一手 → 标记死子、确认或续弈 → 结算/复赛 | 用半透明和叉号区分死子；预览分数与确认状态常驻，不依赖颜色或动画。 |

共享原则：对局输入以房主快照为准；等待、提交、断线与可执行动作分别呈现，不用假进度代替网络状态。操作优先级是当前游戏行为 → 设置、邀请、重连等平台操作 → 离开；安全区优先于撑满前景。UI/Mod 热更保留 Session 与可恢复的本地焦点。新增棋类不需要过渡动画。其他平台/游戏维持各自的减少动态效果处理。
