# 星际派对首页与 i18n（0.1.6）

客户端已采用 [v0.3 设计方向](design/README.md)，实际首页由原生 Godot Control、矢量贴图和绘制层组成。布局适配手机竖屏与电视横屏，并处理 iOS 安全区域。SVG 设计画板是视觉参考，实际运行不是整张图片上的热区。

## 已实现

- 启动直接进入“星星大作战 / NovaParty”首页，只有选择游戏、加入游戏两个主入口；设置在底部，移除昵称入口。
- 黄色星星主角轻微浮动，小星星以不同速度沿椭圆轨道公转，并有轻微大小变化。装饰不接收输入、不移动按钮位置；装饰层最多 30 fps 重绘。
- 天空按设备当地时间，在四个蓝色锚点间轻微变化；不请求天气、定位或服务器时间。静态彩带留在周边。
- 设置中的“减少动态效果”立即冻结公转、大小变化和浮动，保留当前姿态并保存。隐藏首页后暂停其处理；进入游戏不继续绘制大厅动画。
- 中英文默认跟随系统；设置可选择简体中文、English 或系统语言，立即应用并保存。平台标题、按钮、设置、房间信息、错误，以及内置游戏的回合/胜负/暗牌提示已本地化。
- 设置可在首页和对局中打开，方向键与 Tab 导航保持在面板内；关闭恢复入口焦点。对局中切换语言重新渲染过滤快照，不改变规则状态或发送游戏操作。
- 返回键先关闭设置 / 返回首页；对局中离开需要确认。Debug 的显式 `room.leave` 保留直接离开语义。

选择游戏打开封面网格：手机两列、电视三列（超宽四列）；卡片显示游戏名、人数和明确的选中状态。最后一项为加号“添加游戏”，仍调用真实文件选择器安装可信 ZIP。确认游戏卡片后焦点移至“启动游戏”，此时按返回只回到所选卡片，再按返回才回首页。选择页底部只保留返回与“启动游戏”，只有列表滚动；电视把底部操作合并为一行，手机上下排列。右侧滚动条使用浅蓝圆角滑块，并与卡片及上下边缘保留间距。昵称不再提供设置，身份继续自动保留于本地档案和网络会话中。

内置游戏有专用矢量封面，其他游戏默认使用星星封面。外部游戏可在 manifest 提供可选 `cover` 相对路径，并将该资源列入 `files`；支持 PNG/JPEG/SVG。不能读取时回退默认封面。封面不参与规则指纹，完整包指纹仍变化。

加入游戏沿用同一游戏网格，仍输入真实朋友设备地址，并明确说明附近游戏搜索在开发中；没有模拟发现结果。音效、音量控制与持续背景音乐未加入本版。各游戏继续使用自己的棋盘和牌面美术。

## 代码入口

| 文件 | 职责 |
| --- | --- |
| `app/ui/party_home.gd` | 响应式首页、天空时间变化、主角与公转装饰、按钮焦点 |
| `app/ui/game_library.gd` | 响应式游戏封面网格、选中反馈、默认封面及添加入口 |
| `app/ui/party_theme.gd` | 平台按钮材质、字体、焦点与圆角 |
| `app/ui/settings_panel.gd` | 场景内的设置遮罩、可滚动内容及完成按钮 |
| `app/i18n.gd` | 自动加载翻译、语言选择、游戏名称显示 |
| `i18n/zh_CN.json`、`en.json` | 平台文案与占位符；导出时明确包含原始 JSON |
| `mods/<id>/locale-en.json`、`locale-zh.json` | 各游戏自身的显示文案，作为表现资源随 Mod 携带 |

工程名和桌面用户目录统一为 `NovaParty`，英文品牌为 NovaParty，中文显示名仍为“星星大作战”；实际窗口标题由当前语言设置。Android / iOS 包 ID 为 `org.novaparty.prototype`。应用尚未分发，本次直接切换身份，不迁移旧包的数据；局域网发现和加入二维码也使用新的 NovaParty 标识。

## 后续 i18n 开发规则

1. 平台文案使用稳定 key，放入两份平台目录；控件静态文本可直接赋 key，动态句子使用 `tr(key)` 后格式化完整句子，不用拼接词序。
2. 中英文 key 和 `%s` / `%d` 等占位符必须一致。输入的昵称、地址、游戏 ID、请求 ID 不翻译；用户数据与规则消息不得随语言变化。
3. Mod 自带文案目录并列入清单 `files`，不要放进 `rules_files`。示例 `_t()` 通过当前表现脚本的构建根相对路径读取 JSON，不硬编码 `res://mods/...`，因此唯一命名空间热更新仍可用。
4. Mod 不依赖新平台的翻译注册：即使旧 SDK 1 宿主没有平台目录，它也能读取自己的英文/中文文案；不支持的语言回退英文。语言切换后重新 render 本玩家视图，保留焦点与选中状态。
5. 外部游戏可提供 `localized_names` 映射。它只影响表现，不参与规则指纹；完整包指纹仍会随清单变化，协议 1 仍要求完整包匹配。
6. 新语言还需加入平台加载列表、语言选择器和字体覆盖验证。本版只声明已支持简体中文、英文，未验证 RTL、多复数形式或其他字体体系。

## 验证与证据

```sh
python3 tests/i18n.py
Godot --headless --path . --script tests/ui.gd
Godot --headless --path . --script tests/mod_i18n.gd
Godot --path . --script tests/capture_home.gd
python3 tests/home_ios.py --device <UDID>
```

`tests/ui.gd` 的 38 项检查包含真实首页入口、电视焦点、返回确认、语言切换、游戏文案、系统安全区域、轨道随时间变化、减少动态效果冻结和保存、隐藏暂停、设置面板范围、模态焦点以及选牌焦点保持；另验证封面选择与真实启动参数一致、末位添加入口、默认封面、横竖屏列数和固定底栏。单独的 Mod 测试清除平台翻译后验证两种语言、英文回退和玩家状态不变。

iPhone 模拟器测试实际重启中英文客户端，读取 `ui.status` 验证时间及轨道持续变化，进入真实房间后暂停动画，离开后恢复；录制 6 秒原生模拟器视频。产物：

- `build/validation/iphone-home-motion.mp4`
- `build/validation/iphone-home-zh.png`、`iphone-home-en.png`
- `build/validation/iphone-game-en.png`
- `build/validation/home-ios.json`
- 桌面横竖屏、设置面板与加入表单截图 `build/validation/home-*.png`、`library-*.png`

截图和动效视频来自真实应用运行；不代表真实 iPhone 或电视上的本版性能已验证。已有 TCP、Debug、热更新和完整对局回归仍需一起运行。外部包安装与清理共享同一 Godot 用户目录，`tests/integration.py` 和 `tests/hot_integration.py` 应顺序运行，避免相互清理临时 ZIP。

Debug 包新增只读 `ui.status`，返回页面、语言、减少动态效果标记、动画时间、轨道位置、逻辑尺寸和当前本地化标题。它不提供设置写入接口；Release 依旧不包含 Debug 服务。

0.1.7 起以上 UI 脚本、平台翻译与全部 UI 资源可整体热更新；稳定宿主保留活跃 Session。参见 [UI 更新契约](client-ui-updates.md)。


## 声音与电视焦点

首页和游戏库采用 itch.io 的 Soft UI SFX Free（heyheythere，CC BY 4.0），提供方向移动、确认、返回、启动和首次欢迎的短音；设置里可关闭“界面音效”，偏好持久保存。作者、来源与授权链接在设置中显示，原始许可与文件映射随 assets/audio/ui 分发。

电视焦点改为橙金色 #FF8A1C 6px 边缘、深色外轮廓和奶白内边；按钮放大 4.5%，卡片放大 3.5%，150ms 进入，0.65Hz 缓慢呼吸光晕。减少动态效果时保留静态放大/亮边，停止缩放过渡、呼吸及页面渐显。低性能电视使用轻量画布描边，无需 HDR bloom。图层不遮挡文字，卡片不裁掉外侧焦点。

音效使用原始 OGG 字节加载，整包 UI 热更新包含 assets/audio 并重写资源前缀，无需设备导入器或新增原生能力。tests/ui_feedback.gd 校验实际非零 PCM 混音、放大、减少动态、静音停止与偏好保存。
