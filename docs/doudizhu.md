# 斗地主 0.2.0

独立可信 Mod，源码 `mods/doudizhu`，验证首版需求中的「一种具体扑克玩法」：私有手牌、公开底牌的时机、三人轮转、叫分和跨局积分。牌面、封面均为本项目自绘。需要支持 SDK 2 及平台观战的新基座。旧基座可继续运行斗地主 0.1.0，但不能加入 0.2.0 房间；客户端仍只内置五子棋。

## 开始玩

1. 在开房设备导入 `build/mods/doudizhu-0.2.0.zip`，选中斗地主。电视选「仅观战」建公共牌桌，三位玩家各用自己的设备加入；只有三台手机时，手机房主选「我也玩」。
2. 通过附近列表、扫码或地址加入。缺包时先确认下载，再选择加入游戏或观战；密码房需输入密码。
3. 满 3 位玩家后房主点「开始游戏」。开局后不再新增玩家，但可接纳最多 4 位观众。玩家掉线会暂停、重连后继续；观众掉线不影响对局。

## 规则（默认玩法）

- 54 张，每人 17 张，留 3 张底牌。首位叫分者每局轮换。
- 叫分：依次叫 1–3 分或不叫，必须高于当前分；叫 3 分立即成为地主；三人都不叫则重新洗牌发牌（局数不变）。
- 地主拿底牌（此时底牌对所有人公开）并先出。跟牌须同牌型、同张数且更大；炸弹压一切非王炸，王炸最大。两家都不出时，上一手出牌者自由出牌。
- 牌型：单张、对子、三张、三带一、三带二、顺子（≥5）、连对（≥3 对）、飞机（≥2 组连续三张，可带同数量的单张或对子）、四带二（两张单牌，可为一对）、四带两对、炸弹、王炸。顺子、连对、飞机不含 2 和大小王；飞机带的单张不能同时是两张王。
- 计分：叫分 × 倍数。每个炸弹或王炸 ×2；春天（地主胜且农民一张未出）或反春（农民胜且地主只出过一手）×2。地主赢得或输掉 2 份，每位农民各 1 份，三人合计恒为 0。所有玩家同意后再来一局，积分累计。
- 首版不包含：加倍/明牌、出牌计时与托管、癞子等变体规则。

## 界面

- **手机**：上家在左、下家在右，各显示头像、名字、地主/农民、剩余张数和最近一手；底部扇形手牌，点选的牌会抬起；「提示」依次给出能大过上家的组合（不拆对子、三张优先），「出牌」只在选中的牌合法且能大过上家时可用；返回键先清空选择。
- **电视玩家位**：同样布局、更大的牌；遥控器左右选牌、确认键选中、上键到操作按钮。
- **公共牌桌**：三位玩家并排，只显示出牌、叫分、剩余张数、已公开的底牌和结算分数；结算后也不显示未出的手牌。
- 选牌震动 `haptic:tap`，提示 `haptic:select`，出牌/开始/再来一局 `haptic:confirm`，被拒绝的操作 `haptic:warn`（旧宿主会忽略）。

## 隐私

`view_for` 返回本座位手牌，以及终局供参赛者回看的 `revealed`；`view_for_spectator` 始终不含这两个字段。底牌在确定地主前为空数组。任何快照都不含内部牌堆、随机种子或洗牌计数。

## 测试

```sh
Godot --headless --path . --script tests/unit/doudizhu.gd       # 牌型/比较/叫分/计分/隐私 + 300 局机器人对局
Godot --headless --path . --script tests/unit/doudizhu_ui.gd    # 界面检查；加 -- --capture 输出截图
python3 tests/integration/doudizhu_network.py                    # 公共牌桌 + 3 个客户端真实 TCP 整局
```

截图位于 `build/validation/doudizhu/`。`describe_actions` 的 `legal_actions` 列出提示组合与「不出」，任何合法且能大过上家的组合都会被接受。
