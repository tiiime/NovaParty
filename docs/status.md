# 星星大作战开发现状

更新日期：2026-11-02。此文记录当前实现与验证边界；早期需求草案、历史版本记录不代表全部已经交付。

## 阶段与版本

当前是可多设备试玩、支持可信 Mod 扩展的开发原型。局域网启动/发现/加入、缺包传递、实际对局、开发调试和更新已经形成闭环；完整麻将/扑克玩法、正式发行与真实 iPhone 验证尚未完成。

- 引擎：Godot 4.6.1。
- 基础客户端：0.1.13，Android 支持 ARM32 / ARM64。
- 最新体验：0.1.13 基座已打入最新选择流程、音效和焦点效果，仅内置五子棋；跳绳与暗牌示例作为外部 Mod 保留源码。Android Debug/Release APK 已构建，iOS 导出内容已检查。
- SDK 清单版本 1、UI ABI 1；网络协议保留版本兼容。接口仍处于验证期，没有承诺长期稳定。
- 产品模型：每台设备都是完整客户端，没有中心服务器；每局由发起设备运行权威规则，并向参与者发送各自可见状态。

## NovaParty 更名

应用尚未分发，直接切换为 NovaParty：工程/英文品牌、`org.novaparty.prototype` 包 ID、Java 包路径、导出插件与原生扩展路径、`novaparty_debug` 特性、`_novaparty._tcp` 发现服务、`novaparty://join?` 二维码，以及 `novaparty-mod` Skill 均已同步。中文名仍是“星星大作战”，版本保留 0.1.13。

## 已完成的能力

| 模块 | 当前实现 |
| --- | --- |
| 身份 | 自动生成本地稳定 ID，显示昵称/短代号；不要求账号，不再提供昵称设置入口 |
| 局域网联机 | TCP 游戏通信、Android NSD / Apple Bonjour 自动发现、手动地址加入 |
| 加入流程 | 选中发现的游戏；本地有兼容规则则加入，否则提示确认下载、显示进度、校验安装后继续加入 |
| 二维码 | SDK 提供会话连接信息与二维码纹理；默认等待显示，Mod 可控制布局；手机提供相机扫码入口 |
| 普通 SDK 传包 | 活动游戏自动共享 Mod；另有不创建游戏会话的独立 A→B ModSender；不是 Debug 上传接口 |
| 消息与状态 | 身份/座位校验、操作版本、关联回执、去重、心跳；公开状态与玩家私有状态在发送前过滤 |
| 恢复 | 活跃会话内保留座位与恢复凭据；普通客户端可手动重连，独立常驻控制器支持自动恢复和操作重试 |
| Mod | 清单、规则/表现分离、内容指纹、安装与重启恢复、不可变版本命名空间、已知兼容版本复用 |
| 动态人数 | 可选 Drop-in：随时加入/离开、槽位复用、代次隔离；已用于跳绳，默认棋牌仍是双人模式 |
| AI 开发 | SDK 文档、参考 Mod、打包工具和仓库内的 novaparty-mod Skill；另有 Debug RPC 与常驻玩家工具 |

二维码不包含玩家恢复凭据或 Debug token。传包具备大小/路径/完整性/指纹校验，但可信 Mod 仍能执行代码，当前没有脚本沙箱或发送者身份认证。

## 游戏现状

| 游戏 | 版本 | 可玩内容与剩余工作 |
| --- | --- | --- |
| 五子棋 | 0.2.0 | 手机/电视布局，用户身份、当前回合、双方累计用时，断线暂停，结果弹窗、双方同意重赛；不按超时判负 |
| 暗牌比大小 | 外部示例 Mod | 双方私有手牌、并行提交、三轮揭晓与结算；用于验证隐藏信息，不是标准扑克玩法 |
| 跳绳 | 外部 Mod 0.1.1 | 自选展示/控制器角色，需加速度传感器；最多 5 台设备、4 个运动控制器，随时加入/离开，动物排布、校准和累计次数，等待时由 Mod 自控二维码 |
| 围棋、国际象棋 | 未实现 | 尚无对应 Mod |
| 麻将、具体扑克玩法 | 未实现 | 私有信息与并行操作基础已具备，固定多人会话、响应窗口与优先级/超时 API 仍需实际玩法推动完善 |
| 格斗等实时游戏 | 未实现 | 尚无实时输入同步、预测或回滚网络方案，不把当前棋牌同步当作现成方案 |

跳绳动作目前按加速度峰值做简单计数。真机传感器和静止校准已经验证，真人跳跃识别准确率、误触发率尚未完成实测。

## 客户端体验

- 首页使用黄色星星、蓝色天空与软糖按钮；天空随时间轻微变化，小星星公转与缩放，支持减少动态效果。
- 首页主入口为“选择游戏 / 加入游戏”。游戏库为带封面的网格，默认封面可回退，“添加游戏”位于末项。
- 确认卡片后聚焦“启动游戏”；此时返回先回所选卡片，再次返回回首页。选择页只有返回与启动，不放设置。
- 手机触屏与电视遥控器分别适配；固定底栏、滚动内容内边距、圆角滚动条及显式焦点导航已实现。
- 聚焦按钮放大 4.5%、卡片 3.5%，使用橙金亮边、深色外轮廓与轻量呼吸光晕；减少动态时保留静态焦点。
- 平台及内置 Mod 支持简体中文/英文。音效来自 itch.io 免费 Soft UI SFX Free，保留 CC BY 4.0 署名，可关闭并保存偏好。

## 更新与调试

| 更新对象 | 当前方式 | 边界 |
| --- | --- | --- |
| Mod 界面/资源 | Debug 网络上传、局中激活、回退、重启恢复 | 同规则指纹；局中不迁移新规则 |
| 客户端 UI | 完整 UI 包热更新 | 保留 Session 和 Mod 视图；平台页面、字体、图片、翻译、音频可更新 |
| SDK / 原生代码 / 权限 / 引擎 | 安装新 APK 基座 | 不能由 UI/Mod 热更替代 |
| Debug APK | 认证 HTTP 上传后触发系统安装 | 同包名、同签名、Debug 标志、版本和 SHA 校验；通常仍需系统确认，不绕过厂商策略 |

Debug RPC 提供玩家可见快照、合法操作、最终回执、事件订阅和房间管理。工具有 `nvctl.py`、`apkctl.py` 及常驻玩家。Release 排除开发服务、APK 更新原生类和安装权限。普通 SDK 的发现、Mod 传包和二维码能力不依赖 Debug 服务。

热更新有准备失败回退和启动保护，不保证捕获任意脚本的延迟错误、死循环或引擎崩溃。历史 UI 包缓存有容量上限，当前仍需开发阶段维护。
