# UNO · 聚会叠加版 0.1.0

独立可信 Mod，源码 `mods/uno`。使用 108 张基础牌的数值与功能分类，参考 [Mattel 基础说明](https://service.mattel.com/instruction_sheets/W2085.pdf)；叠加、自由 +4 与数字开局是本 Mod 的聚会约定，不能当作官方标准规则。牌面与封面为本项目自绘，不使用官方图像资源。

## 开始玩

需要 **NovaParty 0.1.14 基座**，包含新增的 `fixed` 固定多人会话。旧基座不能仅靠热更新 UNO 或客户端 UI 获得 SDK 能力。

1. 电视与参与者先安装新基座。客户端仍只内置五子棋。
2. 电视“添加游戏”导入 `build/mods/uno-0.1.0.zip`，选择 UNO 并启动。
3. 默认勾选“公共屏幕”，电视不拿牌；2–6 位玩家各用自己的手机或电脑加入。缺包时，通过普通 SDK 展示下载确认、校验安装后自动加入；也可扫码加入。
4. 人数到齐，电视遥控器选择“开始对局”。手机只收到自己的手牌。
5. 若两个人仅用两台手机，发起端在等待页关闭“公共屏幕”，自己也参与发牌。

公共屏幕占一个连接坐席；清单允许最多 7 个连接，但参与发牌最多 6 人。开始后成员锁定，新身份不能中途加入；原玩家断线会暂停，凭原凭据重连后继续同一局。需要换人时由房主退出并重新发起。固定会话不复用旧玩家座位，也不提供主机迁移。

## 聚会规则

- 每人 7 张；开局弃牌为数字牌。房主参与时视为首位发牌者，下一位先手；公共屏幕模式从玩家列表第二位先手。
- 同颜色或同符号可出。跳过牌跳过下一人；反转牌改变方向，双人时等同跳过。
- **+2 可接 +2 或 +4；+4 只能接 +4**。叠罚期间忽略颜色，罚牌累加；不叠加时一次摸完并失去本回合。
- 万用牌与 +4 自由选色；+4 不要求手里没有同色牌，没有质疑机制。
- 可主动摸一张，即使原手牌可出。摸到可出的牌时可出该张或保留；不能改出旧手牌。摸到不可出的牌则自动轮转。
- 剩一张前可勾选“喊 UNO”，随出牌一起声明。忘喊后，在下一次有效出牌／摸牌／不出之前，可补喊，其他玩家也可抓漏喊罚摸两张。失败的非法行动不会关闭这个窗口。
- 牌堆用尽时，保留当前弃牌顶牌，其余弃牌确定性洗回。极端情况下没有可回收的牌，只摸实际可用数量，不生成新牌。
- 先清空手牌者获胜；最后一张为罚牌时先让下一位结清罚牌，再结算，不再继续叠加。数字按点数、功能牌 20、万用牌 50 计本局得分。首版只做单局，不累计至 500 分。
- 所有实际玩家同意后重赛；公共屏幕不投票。保留同一会话与身份，重新发牌。

## UI 与隐私

视觉重设计见 [UNO 独立 UI 规范与效果稿](design/uno/README.md)。已接入木桌、围桌动物头像、彩色大符号牌面、底部浅扇形手牌及菜单；细部动画与弹窗继续按规范完善。

电视显示公共牌桌、参与者昵称、手牌数量、当前回合、弃牌、当前颜色、方向与累计罚牌；没有玩家手牌、摸牌或抓牌操作。等待期间持续显示加入二维码与地址，直到开始。

手机/电脑显示自己的可横向滚动手牌。出牌使用可聚焦按钮，万用牌弹出颜色选择；手机触控先选中抬起，再点出牌；遥控器聚焦后确认出牌，不额外处理模拟鼠标。字号、按钮、焦点与中英文目录随 Mod 提供。结束弹窗包含胜者、得分、重赛、退出与查看牌桌；过时版本的重赛同意只重试用户已经表达的意图。

`view_for` 仅返回本玩家手牌，公共屏幕的 `hand` 始终为空；不发送其他手牌、牌堆顺序、随机种子。房主权威进程仍掌握完整状态，沿用可信房主和可信 Mod 模型。Debug 合法操作只根据过滤后的视图计算，并处理 JSON 数字变为 float 的情况。

## 开发与验证

```sh
python3 tools/pack_mod.py mods/uno build/mods/uno-0.1.0.zip
python3 tools/pack_mod.py mods/uno build/mods/uno-0.1.0-hot.zip --hot
Godot --headless --path . --script tests/uno.gd
Godot --headless --path . --script tests/uno_ui.gd
python3 tests/uno_network.py
```

验证包括 2/3/6 玩家确定性完整对局、108 张牌守恒、非法操作、叠罚、双人反转、抽牌后限制、漏喊窗口、回收、最终罚牌、计分和重赛。UI 测试覆盖中英文、实时语言切换、手机/电视布局、六人短屏、焦点、颜色弹窗和错误提示保留。

真实 TCP 测试使用公共屏幕 + 3 位客户端：普通 SDK 下载确认、隐私、开局后停止 mDNS 发布、拒绝迟到身份、切断连接后暂停与同座位重连、完整出牌及一致同意重赛。Android ARM64 手机/电视模拟器另验证了 SDK 下载确认按键、电视遥控开局、手机实际 adb 触屏出牌与公共屏幕手牌为空。该记录不代表真实电视、真实手机或 iPhone 已验证新版本。

本地截图与报告位于 `build/validation/uno-*.png`、`build/validation/uno-android/`，不提交含私有手牌的运行诊断。基础包导出检查仍确保只内置五子棋，UNO 必须独立导入/接收。
